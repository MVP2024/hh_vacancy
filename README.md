# HH Search Job

Этот проект предназначен для поиска и анализа вакансий с сайта HeadHunter (hh.ru) и сохранения информации о них в базе данных PostgreSQL. Он предоставляет инструменты для взаимодействия с пользователем, позволяющие получать информацию о компаниях, вакансиях и зарплатах.

## Описание

Проект состоит из нескольких модулей:

*   **api/**: Содержит модуль `hh_data.py` для взаимодействия с API HeadHunter. Класс `HeadHunterData` позволяет получать данные о вакансиях по ID компании.
*   **db/**: Содержит модули для работы с базой данных PostgreSQL:
    *   `db_creator.py`: Модуль для создания базы данных.
    *   `db_manager.py`: Модуль, содержащий класс `DBManager` для выполнения операций с базой данных (получение списка компаний и количества вакансий, списка всех вакансий, средней зарплаты и т.д.).
*   **logger/**: Содержит модуль `logger.py` для настройки логирования.
*   **src/**: Содержит основной модуль `main.py`, который запускает программу, создает базу данных, заполняет таблицы и предоставляет пользовательский интерфейс.
*   **utils/**: Содержит модуль `config.py` для чтения параметров конфигурации из файла `database.ini`.

## Установка и настройка

1.  **Клонируйте репозиторий:**

    ```
    git clone <your_repository_url>
    cd hh_search_job
    ```

2.  **Создайте виртуальное окружение (рекомендуется):**

    ```
    python -m venv .venv
    source .venv/bin/activate  # Linux/macOS
    .venv\Scripts\activate  # Windows
    ```

3.  **Установите зависимости с помощью Poetry:**

    ```
    poetry install
    ```

4.  **Настройте параметры подключения к базе данных:**

    *   Скопируйте файл `database.ini.example` в `database.ini`:

        ```
        cp database.ini.example database.ini  # Linux/macOS
        copy database.ini.example database.ini  # Windows
        ```

    *   Отредактируйте файл `database.ini`, указав свои параметры подключения к PostgreSQL:

        ```ini
        [postgresql]
        host=your_host        # Хост базы данных (например, localhost)
        database=your_database  # Имя базы данных
        user=your_username      # Имя пользователя базы данных
        password=your_password  # Пароль пользователя базы данных
        port=5432              # Порт базы данных (обычно 5432)
        ```

        **Важно:** Убедитесь, что файл `database.ini` добавлен в `.gitignore`, чтобы ваши учетные данные не попали в репозиторий.

5.  **Запустите программу:**

    ```
    poetry run python src/main.py
    ```

## Использование

После запуска программа предложит вам выбрать действие из меню:

1.  **Получить список компаний и количество вакансий:** Выводит список всех компаний и количество вакансий, найденных для каждой компании.
2.  **Получить список всех вакансий:** Выводит список всех вакансий с указанием названия компании, названия вакансии, зарплаты (если указана) и ссылки на вакансию.
3.  **Получить среднюю зарплату по вакансиям:** Выводит среднюю зарплату по всем вакансиям, для которых указана зарплата.
4.  **Получить список вакансий с зарплатой выше средней:** Выводит список вакансий, у которых зарплата выше средней по всем вакансиям.
5.  **Получить список вакансий по ключевому слову:** Выводит список вакансий, в названии которых содержится указанное ключевое слово.
6.  **Выход:** Завершает работу программы.


## Зависимости

Проект использует следующие библиотеки:

*   `psycopg2`: Для работы с базой данных PostgreSQL.
*   `requests`: Для выполнения HTTP-запросов к API HeadHunter.
*   `configparser`: Для чтения параметров конфигурации из файла `database.ini`.
*   `Poetry`: Для управления зависимостями и сборки проекта.

## Логирование

Проект использует библиотеку `logging` для логирования событий. Логи сохраняются в файлы в директории `logger/log_files`.
